# EarGuard UI icons

Place **PNG** files in this folder (`assets/icons/`). Recommended: **48×48** or **72×72**, transparent background, single-color line art (`#1E1E1E`).

After adding a file, uncomment its line in `src/components/assetIconRegistry.ts`.

## Required filenames

| File | Used for |
|------|----------|
| `icon-chart.png` | Weekly bar chart, analytics, “See more calls” |
| `icon-timer.png` | Interval / duration / points |
| `icon-streak.png` | Day streak |
| `icon-phone.png` | Active call, call rows |
| `icon-settings.png` | Settings |
| `icon-info.png` | About / info |
| `icon-back.png` | Back navigation |
| `icon-shield.png` | Protection / EarGuard status |
| `icon-sound.png` | Reminder sounds |
| `icon-bell.png` | Notifications |
| `icon-moon.png` | Quiet hours |
| `icon-check.png` | Success / selected |
| `icon-close.png` | Dismiss / close |
| `icon-warning.png` | Warnings / permissions |
| `icon-chevron-right.png` | Forward actions |
| `icon-play.png` | Play sound / test |
| `icon-vibrate.png` | Vibration tests (Testing Suite) |
| `icon-bar-chart.png` | Optional alternate chart glyph |

Until PNGs are added, the app uses built-in vector icons automatically.
